# MES Система оптимизации производственного планирования

Десктопное приложение на Python для импорта данных из SAP ERP (Excel), выполнения оптимизационного планирования по математической модели и визуализации результатов в виде диаграммы Ганта.

## Требования

- Python 3.10+
- Установленные зависимости (см. requirements.txt)

## Установка

1. Клонируйте репозиторий или скопируйте папку `proton_mes`.
2. Установите зависимости:

```bash
pip install -r requirements.txt
```

## Использование

1. Подготовьте Excel-файлы, выгруженные из SAP, в папке `Attachments_...` (или любую другую).
2. Запустите приложение:

```bash
python main.py
```

3. В интерфейсе:
   - На вкладке **Планирование** загрузите данные (кнопка "Загрузить Excel файлы").
   - Установите параметры оптимизации (горизонт планирования, ставка дисконтирования).
   - Запустите оптимизацию кнопкой "Запустить оптимизацию".
   - Просмотрите результаты в таблице и на вкладке **Диаграмма Ганта**.
   - При необходимости добавьте аварийные остановки на вкладке **Управление остановками**.
   - Экспортируйте план в Excel.
   - Для получения справки по структуре данных перейдите на вкладку **Справка**.

## Пример данных

Приложение ожидает следующие файлы Excel (имена могут отличаться, но структура должна соответствовать):

- `заказы дебл.XLSX` – заказы с полями: Заказ AUFNR, Код изделия, Количество заказа, СрокНачала/Базис, БазисСрокКонца, ПользовСтатус.
- `AFKO_рр заказы номера техкарт.XLSX` – связь заказ-техкарта.
- `AFVC_данные к операции_айди рабочего места, вид ра.XLSX` – операции.
- `AFVV_данные от техкарт по структуре операции Колич.XLSX` – нормативы времени.
- `CRHD_V1_рабочее место номер и название краткое.XLSX` – рабочие места.
- `CSLT_виды работ_текст.XLSX` – виды работ.
- `KAKO_мощность.XLSX` – мощности.

Все файлы должны находиться в одной директории. Приложение автоматически связывает данные по ключам.

**Примечание**: Если какие-либо файлы отсутствуют или в них недостаточно обязательных столбцов, приложение выведет подробное сообщение об ошибке с указанием, что именно требуется.

## Функциональность

- **Импорт данных**: загрузка всех необходимых Excel-файлов, автоматическое связывание по ключам.
- **Контроль загрузки данных**: автоматическая проверка наличия всех необходимых файлов и столбцов, вывод подробных сообщений об ошибках с указанием отсутствующих файлов и требуемых колонок.
- **Оптимизация**: линейное программирование (PuLP) с целевой функцией максимизации дохода и учетом ограничений по ресурсам, технологиям, спросу.
- **Визуализация**: интерактивная диаграмма Ганта с цветовым кодированием и подсказками.
- **Управление аварийными остановками**: ввод данных об остановках, пересчет плана.
- **Экспорт**: сохранение плана в Excel, диаграммы в PNG/PDF.
- **Раздел справки**: встроенная справочная информация о структуре данных, необходимых файлах и колонках, доступная через вкладку "Справка" в интерфейсе.
- **Логирование на русском языке**: все системные сообщения логирования выводятся на русском языке для удобства пользователя.

## Математическая модель

Приложение реализует упрощенную версию модели, описанной в техническом задании. Основные элементы:

- Целевая функция: максимизация дисконтированного дохода.
- Ограничения: по ресурсам (мощность рабочих мест), технологические, по спросу, по срокам жизни.
- Учет затрат на переналадку (опционально).

## Устранение перекрытий задач

После оптимизации выполняется пост-обработка назначений, чтобы устранить перекрытия задач на одном рабочем месте в одном периоде. Задачи распределяются последовательно внутри рабочего дня.

## Примечания

- Приложение автономно, не требует подключения к SAP.
- Для работы с другими наборами данных может потребоваться адаптация mapping-колонок в `data_loader.py`.
- Оптимизационная модель является демонстрационной; для промышленного использования рекомендуется доработка.
